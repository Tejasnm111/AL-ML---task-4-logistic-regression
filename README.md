# AL-ML---task-4-logistic-regression

## Objective

The objective of this project is to build a binary classification model using Logistic Regression. The project demonstrates the complete machine learning workflow including data preprocessing, model training, evaluation, and visualization.

## Tools Used

Python

Pandas

NumPy

Scikit-learn

Matplotlib

## Dataset

Breast Cancer Wisconsin Dataset

## Steps Performed

1. Imported the dataset.
2. Checked dataset information.
3. Handled missing values.
4. Encoded categorical variables.
5. Split the dataset into training and testing sets.
6. Standardized the features.
7. Trained a Logistic Regression model.
8. Predicted the target values.
9. Evaluated the model using Accuracy, Precision, Recall, ROC-AUC, and Confusion Matrix.
10. Plotted the ROC Curve.

## Evaluation Metrics

Accuracy

Precision

Recall

ROC-AUC Score

Confusion Matrix

## Results

The Logistic Regression model successfully classified the dataset into two classes. The evaluation metrics showed the model's performance, and the ROC curve was used to visualize the classification capability.
